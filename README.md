# Order Platform

A microservices-based order management backend built to learn and demonstrate
Java, Spring Boot, Node.js, MongoDB, RabbitMQ and Docker.

## Planned Architecture
- API Gateway
- user-service (Spring Boot + MongoDB)
- product-service (Spring Boot + MongoDB)
- order-service (Spring Boot + MongoDB)
- notification-service (Node.js)
- RabbitMQ for events, Docker Compose to run everything

## Status
In progress. Phase 0 complete.
